# 食在安心—像素大冒險（遊戲功能展示 Demo）

農業部農業藥物試驗所 115 年度「食在安心—像素大冒險」標案之遊戲功能展示。範圍僅限遊戲前台玩法，不含後端、帳號、教育雲 SSO、排行榜伺服器驗證及管理後台。

## 執行

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # 輸出至 dist/，可放在任何靜態網站主機
npm test         # 遊戲邏輯單元測試
```

## 操作

- 移動：方向鍵／WASD、在場地上滑動、左下角虛擬方向鍵
- 爸爸（磁鐵）／媽媽（清除風險蔬果）：右下角按鈕，或 Q／E 鍵
- 標題畫面左上「⚙ 參數調整」：模擬管理後台調整遊戲參數，儲存後下一局套用（展示時可把通關時間調短）
- 標題畫面右上：音樂、音效分別開關

## 架構

依服務建議書之分層設計，遊戲規則不依賴畫面與平台，日後延伸至 App 時僅需替換平台介接層。

| 目錄 | 說明 |
|---|---|
| `src/logic/` | 遊戲邏輯層：移動、計分、計量條、事件、角色功能、卡片解鎖（純 JS，含單元測試） |
| `src/scenes/` | 畫面呈現層：Phaser 3 場景（標題、教學、遊戲、結算、圖鑑、造型） |
| `src/platform/` | 平台介接層：輸入、本機存檔、音訊 |
| `src/config/` | 遊戲參數、事件文案、卡片內容 |
| `src/art/` | 像素佔位美術（字元陣列繪製） |

## 暫定事項

以下為需求規範書未定義、Demo 先行採用之暫定值，均可於參數中調整，正式版與機關確認：

- 事件觸發後該計量條歸零；兩條同時滿格時風險事件優先
- 貓爪追擊 6 秒，速度約為蛇的一半；磁鐵持續 5 秒、範圍 3 格（含風險蔬果）
- 阿鴻無敵 4 秒，僅影響吃到風險蔬果之效果，不免除撞擊死亡
- 分數不低於 0；蛇身為蔬果籃造型
- 卡片解鎖：過關依序解鎖知識卡 1–10，之後限定卡（草莓→造型、西瓜→夜間背景、葉菜清洗→加速）；草帽造型需 10 張、翻耕農地需 5 張
- 知識卡與事件文案為暫定，正式版經機關專業審定

## 素材

所有圖像為程式繪製之像素佔位圖，音樂音效為 Web Audio 即時合成，不含任何外部素材。正式版角色依《食農探險繪本》重繪，食品標章使用官方圖檔。
